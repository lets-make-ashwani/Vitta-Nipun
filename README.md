# Vitta Nipun - Finance Education Platform

A premium, mobile-responsive finance education website built with React, Tailwind CSS, and Motion animations.

## 🎯 Overview

Vitta Nipun is a comprehensive finance education platform that combines modern edtech aesthetics with fintech design principles. The platform offers courses in Investment Banking, Financial Modeling, Data Science, Stock Market, FinTech, and more.

## ✨ Features

### 🎨 Design System
- **Brand Colors**: Deep Teal (#0B4F66) and Growth Green (#86B633)
- **Mobile-First Responsive**: Optimized for all devices (320px to 1920px+)
- **Modern UI**: Glassmorphism, smooth animations, and premium aesthetics
- **Professional**: Finance-focused design that builds trust

### 📱 Mobile Experience
- **Hamburger Menu**: Slide-out navigation drawer
- **Bottom Navigation**: Sticky bottom nav for quick access
- **Touch Optimized**: Thumb-friendly buttons and interactions
- **Responsive Grids**: Adaptive layouts across all breakpoints
- **Floating CTA**: Context-aware call-to-action button

### 🎓 Key Sections
1. **Hero Section**: Engaging introduction with animated statistics
2. **Course Categories**: 8 major finance programs
3. **Why Choose Us**: 6 compelling features
4. **Featured Courses**: Detailed course cards with pricing
5. **Placement Section**: Success metrics and hiring partners
6. **Testimonials**: Student success stories
7. **Webinars**: Upcoming events and workshops
8. **Blog**: Finance and career insights
9. **FAQ**: Common questions with accordion UI
10. **Contact**: Multi-channel contact options

### 🚀 Technical Features
- **Smooth Animations**: Motion.js for fluid interactions
- **Performance**: Optimized with lazy loading and efficient rendering
- **Accessibility**: WCAG AA compliant color contrast
- **SEO Ready**: Semantic HTML and meta-friendly structure
- **Type Safe**: Built with TypeScript support

## 📦 Tech Stack

- **React 18.3.1**: Modern UI library
- **Tailwind CSS 4.1.12**: Utility-first CSS framework
- **Motion 12.23.24**: Animation library (formerly Framer Motion)
- **Vite 6.3.5**: Fast build tool
- **Lucide React**: Icon library
- **React Router DOM**: Client-side routing
- **React Intersection Observer**: Scroll animations

## 🛠️ Installation

```bash
# Install dependencies
pnpm install

# Start development server
pnpm dev

# Build for production
pnpm build
```
